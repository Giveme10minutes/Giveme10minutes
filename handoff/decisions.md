# 已定方案

- 将实习面试学习区整合到既有个人网站，从顶部导航及两个项目条目进入。
- 围绕职业探索与学习行动 Agent、Java 社区论坛展开，补充两者共用的工程基础。
- 学习模式解释原理和项目实现。自测模式先展示问题，再由用户展开参考要点。
- “复制问题和上下文”将当前知识点、源码位置、示例和用户输入复制到剪贴板，供用户粘贴到自己选择的聊天窗口。
- 第一版沿用静态 GitHub Pages。浏览器存储笔记、回答、收藏和进度，并支持 JSON 备份。
- 在现有个人网站仓库中管理版本和交接材料。源码项目各自在原仓库维护。

- 原首页保留在站点根路径，沉浸式作品集从首页导航进入，独立发布于 `docs/showcase/`。宽屏使用滚动动画，窄屏顺序展示内容。发布证书采用遮盖编号的副本。
